# Backend Boundary — Phase 4 Only

This directory reserves the future Node.js/TypeScript API within the Seduligma monorepo. It is intentionally not implemented during Phase 0–3.

Only after the canonical PRD Phase 4 trigger and founder approval may this directory receive API, database, authentication, subscription, support, sync, or signed-configuration implementation. It must never become a server-side personal-message dispatcher, remote unlock service, or arbitrary device-command service.
